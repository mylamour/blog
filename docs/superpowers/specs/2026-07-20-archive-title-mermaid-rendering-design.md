# 中文归档标题与 Mermaid 渲染修复设计

日期：2026-07-20

## 背景与根因

最新文章在中文站暴露了两个现有主题问题。

第一，`/blog/` 归档列表的基础布局宽度是 500px，标题最多占 430px，并使用单行省略。英文站已经通过语言专用样式把桌面归档列扩展到 860px，并允许标题占用完整可用宽度；中文站没有获得同一规则，因此较长的中文标题被截断。文章正文页顶部标题已经支持换行，不在本次修改范围内。

第二，Hexo 把 `mermaid` fenced code block 生成成 `figure.highlight.plaintext`。主题在浏览器端读取代码内容并判断是否为 Mermaid，但当前判断要求内容直接以 `flowchart`、`graph` 等声明开头。最新文章的 14 张图都先写了 `%%{init: ...}%%` 指令，因此判断失败，Mermaid CDN 脚本不会加载，页面只显示代码块。

## 目标

- 中文与英文桌面归档页使用相同的宽标题布局，完整显示最新文章标题。
- 保持当前移动端归档布局，不扩大本次改动的响应式范围。
- 正确识别带 Mermaid 初始化指令或前导注释的图表代码。
- 只在页面实际包含 Mermaid 时继续按需加载 Mermaid。
- 保证普通 `plaintext` 代码块不会被误判为 Mermaid。
- 不修改中英文文章正文及 front matter。

## 方案

### 归档标题

把现有英文桌面规则提升为中英文共享规则：在 `min-width: 768px` 下，`.content.content-archive` 使用 `min(860px, calc(100vw - 48px))`，`.item-post .post-title` 使用完整可用宽度。删除只服务英文站的重复宽度规则。

移动端继续使用主题已有的 100% 容器和按屏宽限制标题的规则。本次不把移动归档改成多行列表，也不改变日期、时间线、hover 或归档定位方式。

### Mermaid 识别

在 `load-script.ejs` 中增加一个小型纯函数，先跳过代码开头连续出现的 Mermaid 指令 `%%{...}%%` 和 Mermaid 注释 `%% ...`，再检查第一个有效声明是否属于当前支持的 Mermaid 图类型。

处理边界如下：

- `figure.highlight.mermaid` 视为显式 Mermaid。
- `figure.highlight.plaintext` 只有通过内容识别后才转换。
- 带 `%%{init: ...}%%` 的 `flowchart` 应被识别。
- 带前导 Mermaid 注释的图应被识别。
- 普通文本、Shell、JSON 或只包含 `%%` 字样的内容不得被转换。
- 识别成功后沿用现有行为：替换为 `.mermaid` 容器，按需加载 Mermaid 10，并渲染 SVG。

本次保留客户端按需渲染，不引入 Mermaid CLI、Puppeteer 或构建期 SVG 生成，以避免增加构建时间和依赖面。

## 测试设计

实现遵循测试先行：

1. 新增主题渲染测试，验证带 `%%{init}%%`、带注释和直接声明的 Mermaid 能被识别，同时普通 plaintext 不能被识别。测试直接执行模板中的纯识别函数，避免复制一份测试专用实现。
2. 新增归档 CSS 契约测试，验证桌面宽度规则对所有语言生效，且移动端原有规则仍然存在。
3. 先运行新增测试并确认它们因当前缺失行为而失败，再实施最小修改。
4. 运行 `npm test`、`npm run check:pre-commit`、`npm run check:theme`、`npm run verify:zh` 和 `npm run verify:en`。
5. 检查生成结果：中英文文章路径存在；最新文章保留 14 个 Mermaid 源块；客户端识别函数可将它们全部识别为 Mermaid；普通代码块保持原样。

## 验收标准

- 中文桌面 `/blog/` 与英文站采用相同的 860px 归档列布局，最新中文标题不再受 430px 省略规则限制。
- 英文归档页现有布局不退化。
- 最新中英文文章的 14 张带初始化指令的 Mermaid 图都进入渲染路径。
- 非 Mermaid plaintext 代码块不进入渲染路径。
- 中英文构建与生成审计通过。
- 工作区中已有的 `source/_posts/2026-03-13-Meet-Yourself.md` 不被修改或提交。

## 非目标

- 不修改文章标题文字。
- 不修改文章页顶部标题排版。
- 不把 Mermaid 改为构建期静态图片。
- 不重构主题的全部客户端脚本或归档组件。
- 不处理 Mermaid CDN 不可用时的离线渲染。
